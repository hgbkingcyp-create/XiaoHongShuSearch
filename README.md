# 小红书·性格测试变现项目

> AI 一人公司 → 多人协作。内容在小红书种草，站内开店卖测试商品变现，全链路用 AI 生产。
>
> **新队友先读 [`AGENTS.md`](AGENTS.md)**（AI 协作规范 + 铁律 + 工作流）；策略总纲看 [`执行手册.md`](执行手册.md)（v2.0）。

## 项目是什么

做「娱乐化性格/人格测试」内容，在小红书开店卖测试商品（商品卡 + 搜索流量成交），报告模板化、自动发货、边际成本近零。

**三个不可动摇的前提（三轮调研结论）：**
1. 内容只做「性格/人格测试」，绝不碰算命/占卜/运势/改运（平台零容忍）。
2. 不导流到微信/站外（评论区扣1+私信发外链、谐音暗号都会封号），只走站内商品卡 + 搜索流量。
3. 变现走「低价商品自动发货」，定价 0.99 引流款 + 3.8 利润款（对标已验证的低粉高销模式）。

## 快速开始

```bash
cd app
python3 server.py
# 浏览器打开 http://localhost:8000
```

零依赖，Python 3 标准库即可。

## 如何新增一个测试品类

1. 在 `app/data/` 加一个 JSON（格式照抄 `love.json`）：
   - `questions`：每题 `{id, text, options:[{key,text}...]}`，key 用 A/B/C/D
   - `results`：每个 key 对应一个结果，含 `type/tagline/hook/portrait/strengths/blindspot/advice`
   - 计分规则：选 A/B/C/D 最多的一项命中
2. 在 `content/` 加对应的笔记 `.md`（标题必含「仅供娱乐」）
3. 服务器会自动识别（无需改代码）

## 内容合规红线（发内容前必读）

- ❌ 禁用词：算命、算卦、占卜、八字、风水、塔罗、改运、招财、通灵……
- ✅ 安全方向：性格/人格/MBTI/金钱观/爱情观/职场/社交测试
- ❌ 别用「心理测评」「心理咨询」名义（触发资质审核）
- ✅ 标题统一带「仅供娱乐」
- ❌ 不挂外链、不导流微信、不评论区扣1+私信发外链

详见 `执行手册.md` 第一章。
